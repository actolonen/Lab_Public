# Methods to analyze gene expression data

## Quantify gene expression from different mRNA expression methods
-   [qRT-PCR](./qRT-PCR) quantify mRNA expression changes using the Ct method.
-   [RNA seq](./RNAseq) calculate gene expression from RNAseq FASTQ files
-   [Capp Switch](./TSS) identify transcription start sites (TSSs) from Capp-Switch sequencing data.

## RNAseq analysis methods
-   [Cluster enrichment](./Cluster_enrichment) to assess if clusters of genes are enriched for functional categories.
